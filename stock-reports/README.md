# Stock Reports

Investment reports generated by the `/stock-report` command.

## Structure

Each report run generates three files inside `stock-reports/<stock-name>/<date>/`:

| File | Description |
|------|-------------|
| `<stock>-<date>.md` | Final simplified report — the main deliverable |
| `<stock>-<date>.raw.md` | Full raw analysis (fundamentals, technicals, valuations) |
| `<stock>-<date>.sources.md` | Approved and rejected web sources, data sources used |

## How It Works

The `/stock-report <stock name>` command runs three agents in sequence:

1. **Source Scout** — Gathers data, runs web searches, presents sources for user approval
2. **Stock Analyst** — Performs deep analysis using only approved sources
3. **Report Writer** — Formats the analysis into a clean, simplified markdown report
